# chainoftrust

Install-time trust reports for agent-facing tooling.

Paste a repository URL, get a generated assessment of what installing it would actually do:
what the install path executes, whether published checksums are ever verified, what gets written
into agent configuration, and where a package's provenance does not match its claims.

Free, no account required. Verdicts are public.

Status: V1 under construction. This repository was bootstrapped on 2026-08-09.
